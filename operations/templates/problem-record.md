# Problem Record Template

Use a problem record when separate incidents show the same recurring or systemic failure pattern.

## Required fields

- Problem ID: `PRB-####`
- Title
- Linked incidents (at least two)
- Repeating symptom/pattern
- Business impact across occurrences
- Known error / suspected root cause
- Current workaround
- Permanent corrective action
- Owner
- Status
- Linked change record when permanent remediation requires controlled implementation

## Rule

Incident management restores service. Problem management reduces recurrence. Do not close a recurring pattern merely because the latest incident was mitigated.
